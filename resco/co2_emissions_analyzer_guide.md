## Understanding the Output

### CO2 Values Explanation
- **SUMO outputs CO2 in milligrams (mg)**
- **Script converts to:**
  - Grams (g) = mg ÷ 1,000
  - Kilograms (kg) = mg ÷ 1,000,000  
  - Tonnes = mg ÷ 1,000,000,000

### Vehicle Types in Your Simulation
- **type_eu0**: Older gasoline cars (high emissions)
- **type_eu2**: EU2 standard gasoline cars  
- **DEFAULT_VEHTYPE**: Standard SUMO vehicles (EU4 equivalent)
- **type1_co2**: Heavy trucks (HDV_12_8 class) 
- **type2_co2**: Heavy duty vehicles (HBEFA3/HDV)

### Routes Explanation

- **route_ew/we**: East-West corridors (main traffic)
- **route_nw/en/se/ws**: Medium traffic routes

## File Requirements

### Input File Format
- **SUMO emissions XML file** (typically named `emissions.xml`)
- **Generated by SUMO** with emission output enabled
- **XML structure**:
  ```xml
  <emission-export>
    <timestep time="0.00">
      <vehicle id="vehicle_id" CO2="2624.72" eclass="HBEFA3/PC_G_EU4" .../>
    </timestep>
  </emission-export>
  ```

### File Size Handling
- ✅ **Small files** (< 1 MB): Instant processing
- ✅ **Medium files** (1-50 MB): Fast processing with progress
- ✅ **Large files** (50-500 MB): Optimized streaming with memory management
- ✅ **Very large files** (> 500 MB): Memory-efficient parsing with progress indicators
