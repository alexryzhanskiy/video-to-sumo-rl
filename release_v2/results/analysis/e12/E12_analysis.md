# E12 analysis tables

Generated by `revision/tools/e12_analysis.py` from files only. Means ± SD and 95% CI are across the 5 training runs (unit of replication); for the baselines, across the 5 SUMO seeds of the same files. All evaluation episodes: 1800 s, 3 s yellow + 4 s all-red for the DRL policies, field program for the baselines, `--time-to-teleport -1`. E3 = the original policies (trained yellow-only on one demand file), evaluated with the same clearance on the same files and seeds.
